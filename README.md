# Cisco CCNA Practice Journal 🚀

Welcome to my CCNA hands-on practice repository! Here, I upload my daily Cisco Packet Tracer labs (`.pkt` files) to document my learning progress and practical troubleshooting skills.

## 🛠️ Technologies & Protocols Practiced
* **Routing:** Static Routing, OSPFv2 (Single-Area), Inter-VLAN Routing (Router-on-a-Stick).
* **Switching:** VLANs, Trunking (802.1Q), EtherChannel, VTP, and STP concepts.
* **Security & IP Services:** Standard/Extended ACLs, NAT/PAT, DHCP Server/Relay, and Port Security.
* **Tools:** Cisco Packet Tracer, Cisco IOS CLI.

## 📂 Lab Files Breakdown
* Open the `.pkt` files using **Cisco Packet Tracer** to view the complete topology, device configurations, and routing tables.
* Every lab focuses on configuring network devices from scratch and ensuring 100% end-to-end connectivity.
